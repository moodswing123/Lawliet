# Lawliet — Advanced AI Chat Interface

Lawliet is a production-ready AI chat application with a sleek, intuitive interface inspired by modern chat designs. Built with Next.js, TypeScript, and OpenAI.

## Features

- 🧠 **Streaming AI responses** — Real-time token-by-token output
- 💬 **Conversation history** — Search, rename, and delete chats
- 🌗 **Dark/light mode** — System-aware with manual toggle
- 🔐 **Secure authentication** — Email/password with bcrypt hashing
- ✏️ **Message editing & regeneration** — Refine your conversation
- 📋 **Markdown & code syntax highlighting** — Full formatting support
- 📱 **Responsive mobile design** — Touch-friendly drawer navigation
- ⚡ **Rate limiting** — Protect against abuse
- 🎨 **Minimalist UI** — Clean, professional, distraction-free
